# KothaKhoj

Find rooms and flats for rent. A MERN stack project (MongoDB, Express, React, Node).

## Run locally

Backend:

```
cd backend
cp .env.example .env    # then set SECRET_KEY
npm install
npm run dev             # http://localhost:8000
```

Frontend:

```
cd frontend
cp .env.example .env
npm install
npm run dev             # http://localhost:5173
```

MongoDB must be running locally (database: `kothakhoj`).
